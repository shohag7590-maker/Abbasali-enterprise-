# Abbasali Rent Manager

A bilingual-friendly React application for managing monthly rent, electricity, gas, service and waste bills for **Abbasali Enterprise**.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Features

- Manage tenant details and addresses
- Store advance and previous dues
- Calculate electricity usage and bill
- Calculate rent and monthly charges
- Track payments and balance
- Generate customizable WhatsApp/SMS reminder and confirmation messages
- Save data in browser localStorage
